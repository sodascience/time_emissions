The files in this folder all contribute to create the file gas_profiles.xlsx. 
This file is eventually used to allocate the yearly gas usage of an address in the Netherlands to the months in this year.
The profile fractions were calculated based on the 'Verbruiksprofielen' as defined in the two sources below:

For 2015: 
Profielenmethodiek Aardgas (2.10). (2004). Platform Versnelling Energieliberalisering. https://energiedatawijzer.nl/documenten/profielenmethodiek-aardags/

For 2016:
Herziening temperatuurdefinitie t.b.v. Verbruiksprofielen gas (No. IC121). (2013). Nederlandse Energie Data Uitwisseling. https://energiedatawijzer.nl/app/uploads/Documenten/Topics_MFF/IC121-Herziening-temperatuurdefinitie-verbruiksprofielen-gas-v10.pdf
