# README REPLICATION PACKAGE - INPUT-OUTPUT ANALYSIS

## Folder structure

Classification_manuals: Contains the manuals for classifying household consumption according to COICOP and EXIOBASE

Code: Contains all code to replicate the input-output analysis
	-> Also contains a separate readme file

Data: Contains all data used for the input-output analysis
	-> Also contains a separate readme file

Plots: Contains all plots describing the results of the input-output analysis (expenses; emissions; intensities)



## Correspondence tables

CorrespondenceTables_CBS-EXIOBASE_final.xlsx: Contains all tables relevant for the input-output analysis in an accessible format
	-> Also contains a readme sheet

CorrespondenceTables_CBS-EXIOBASE_preRAS_yyyy.xlsx: Same structure as CorrespondenceTables_CBS-EXIOBASE_final.xlsx but containing the EXIOBASE data from the years 2013-2016 instead of 2015 solely. 
Also, the preRAS product-wise CBS expenditures were used to calculate the intensities instead of the post-RAS product-wise CBS expenditures. Details can be found in the appendix on the Input-Output Analysis.
